# Smart Auto Checkpoint

A Geometry Dash 2.208 Geode mod created by **SoyRiper**.

## Features

- **Smart Key-Event Checkpoints**: Places practice checkpoints ONLY on key events:
  - Landing on solid platforms or slopes (requires 0.35s in air first, preventing ground walking spam)
  - Hitting Orbs, Jump Pads, or Dash Rings
  - Entering Vehicle Portals or changing gravity
- **Pause on Delete ('X' Key)**: Pauses auto-checkpointing for 2 seconds after deleting a checkpoint with the `X` key, making clearing checkpoints effortless.
- **Zero Flight Spam**: Fully configurable options to eliminate mid-air checkpoint clutter.

## Settings

- **Enabled**: Toggle mod on/off.
- **Pause on Delete**: Pauses mod for 2.0s after pressing `X`.
- **Checkpoint on Ground Landing**: Checkpoint when landing on solid ground after a real jump.
- **Checkpoint on Orbs**: Checkpoint when hitting orbs, pads, and rings.
- **Checkpoint on Portals**: Checkpoint when entering vehicle portals.
- **Minimum Cooldown**: Mandatory minimum separation between checkpoints.
